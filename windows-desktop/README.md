# اف Ai برای ویندوز
نسخه دسکتاپ اف Ai با WPF و Microsoft Edge WebView2. برنامه وب‌سایت https://Fizer.ir را در پنجره مستقل ویندوز نمایش می‌دهد.

## ساخت
Workflow با نام **Build Af Ai for Windows** را از زبانه Actions و گزینه Run workflow اجرا کنید. خروجی نصب با نام Af-Ai-Setup.exe در بخش Artifacts قرار می‌گیرد. نصب‌کننده پیش‌نیاز WebView2 Runtime را نیز نصب می‌کند.

نیازمندی توسعه: .NET 8 SDK و Windows.
